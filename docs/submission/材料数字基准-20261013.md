## 其他可引用的工程数字

- 48 向扇形采样 + 批量距离矩阵；服务端通道单次分析约 11-30 秒（缓存命中后秒级）
- 检索预算：基础 5 页/100 条，住宅（人口分母）加倍 10 页/200 条，按上游总数精确收敛
- 测试：vitest 单元 182 项 + playwright 浏览器 34 项（CI 每次推送全绿）
- 插值精度自证：困难地形 MAE 5.73 分钟（31.6%）· 常规街区 3.89 分钟（23.7%）
- 三级通道降级：服务端代理 → 浏览器直连（GL SDK）→ 确定性合成，演示永不中断

## 重制材料操作指引

1. `PORT=8807 npm start`（需 `.env` 真实 AK）；
2. `node scripts/reshoot.mjs` 自动重跑 5 场景并重截 `docs/data/screenshots/` 全部截图，
   结果 JSON 输出到 `.tmp-reshoot-results.json`（数字与本页冲突时以新批次为准并同步本页）；
3. 仅重截双样例用 `node scripts/reshoot-samples.mjs`；
4. PDF 数字替换走 `docs/submission/patch_pdf_batch.py` 管线（PyMuPDF 原位替换，记得 subset_fonts）。
