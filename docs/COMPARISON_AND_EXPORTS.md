# 方案对比与成果导出

对应路线图第 3 项与第 4 项的最小可用范围。依赖本地项目和数据完整性功能；全部比较与报告生成在浏览器本地完成，不消耗百度接口配额。

## 操作顺序

1. 完成体检或导入完整项目，在「规划建议」采纳需要的补点。
2. 打开「方案对比」，点击「记录为 A」。这会复制当前采纳与跳过选择，不会随之后的编辑改变。
3. 继续调整补点；也可清空当前选择，从现状重新选择。点击「记录为 B」。清空不删除已记录的 A／B。
4. 比较现状、A、B；需要修改某方案时先载入，调整后再更新该方案。覆盖已记录方案或替换已有工作台选择时有确认提示。
5. 自动保存会保留 A／B。刷新、打开其他项目后返回、导入／导出项目均可恢复。重新体检则创建新的分析基线，不带入旧方案。
6. 从「体检报告」或「方案对比」底部生成完整报告、设施 CSV 或原报告摘要 JSON。

## 对比的计算口径

共同基线包含社区、人群、时长、报告编号、算法与规则、设施与检索记录、时间场及住宅权重和覆盖掩码。它以规范化字段内容生成确定性标识，用于防止误混方案，不是文件真实性签名。同一参数的两次不同采样也不直接比较。导入另一份基线的方案会拒绝载入，保留当前项目。

对每套方案，复制现状掩码后叠加所有**已采纳**补点的 1 km 直线服务盘：

- **全覆盖率**：菜市场、药店、小学三类都已覆盖的住宅代理权重 / 总住宅代理权重。
- **新增覆盖**：方案全覆盖率减现状全覆盖率，单位为百分点；重叠盘不重复计数。
- **剩余薄弱住宅格**：仍缺任一核心类别且住宅权重大于 0 的格数。
- **剩余缺口权重**：上述薄弱格权重占比。不是缺失设施数量，也不是真实人口数。
- **补点数**：去重后的已采纳点数；跳过的建议不产生覆盖收益。

方案 A／B 中未记录的列显示“未记录”，与已记录的零补点方案区分。住宅样本不足、核心类别检索不完整、缺少版本或使用历史规则时，不能输出可比较的改善值；历史结果可查看和导出。现状总评分保持原值，因为模拟补点没有生成真实设施属性或新检索数据。

## 导出内容

| 入口 | 内容与用途 |
| --- | --- |
| 完整报告 / PDF | 新窗口预览包含地图、图例、中心参数、现状指标、清单、灰色区域、A／B、当前采纳／跳过坐标、来源、版本与警告的报告。点打印后选择“另存为 PDF”。 |
| 设施 CSV | 当前分析的周边已取设施与住宅样本，含名称、类别、坐标、地址、通道、类别检索状态、最早采集时间与规则。不是圈内可达设施全量。 |
| 薄弱社区 CSV | 街道批量任务**完成后**导出成功样本中评分 < 75 或有效覆盖率 < 80% 的小区，附任务编号、导出时间、抽样口径和成功／失败样本数。未知覆盖不当作 0；失败样本不纳入薄弱排名。 |
| 导出 JSON | 原报告摘要，补充已记录的 A／B；不能恢复整个项目。 |
| 导出项目 | 完整可恢复的本地项目，包含 A／B 的原始选择与基线标识。 |

CSV 使用 UTF-8 BOM 和标准引号转义。来自名称、地址等文本的公式前缀会加保护字符，避免表格软件执行公式。没有薄弱样本时文件只有表头。

完整报告从快照几何生成矢量示意图，无在线底图请求，标注 BD-09、方向和近似比例尺。等时线与灰色区域取自原分析，补点编号对应表格；同位置或相邻补点合并编号，精确位置见坐标表。图幅外的采纳点另外提示。地图不代表正式地籍图或建设用地证明。报告中的“原始推荐依据”保留建议产生时的解释；当前组合收益以对比表为准。

浏览器阻止弹窗时，自动下载独立 HTML 报告并提示，打开文件后仍可打印。生成或下载初始化失败时显示提示，不改变项目。浏览器最终文件落盘结果由下载界面反馈；系统没有直接写入用户目录的权限。打印页数随样本、方案和警告长度变化，不限定为固定页数。

## 兼容与未覆盖范围

- 继续使用项目格式 v1，`workbench.scenarios` 为可选扩展；本版本可打开未记录 A／B 的旧 v1 项目。第一批旧客户端不识别该扩展，重新保存会丢弃 A／B，请团队统一更新后再编辑并保留原备份。
- 历史规则不自动迁移为新规则，不会把旧数据重算成新结论。
- 批量任务接口目前没有每个社区完整的报告版本和采集时间，薄弱社区 CSV 不补造这些字段；数据模式与版本需结合原任务核对。
- GeoJSON、真实底图截图、直接无交互 PDF 下载、批量任务持久化、预算成本与真实步行路线核验不在本批范围。

## 验证

运行 `npm run typecheck`、`npm test`、`npm run build`、`npm run test:browser`。浏览器验证沿用专用离线服务、阻断外网且并发为 1；不读取 `.env`，不调用真实 AK。

本批新增计算与导出测试覆盖住宅权重、重叠服务盘、不同类别组合、不可用数据、基线变化、快照隔离和往返、中文 CSV、公式防护、未知覆盖及报告文本转义。浏览器验证 A／B 记录与恢复、报告与页面指标一致、PDF 打印、设施／薄弱社区下载、弹窗兜底、错误提示及窄屏布局。

2026-10-11 本地验收：123 项单元／场景测试、11 项浏览器流程、类型检查和前后端构建通过；最终排版调整后补跑本批 4 项浏览器流程通过。打印样张为 5 页，已逐页检查地图、表格和分页；此为离线功能验收，不是线上 CI 或真实社区结论。

样张和截图由测试写入忽略提交的 `test-results/`，使用合成数据，只用于功能验收；参赛介绍 PDF、视频和真实社区案例需在冻结版本上另行同步。
