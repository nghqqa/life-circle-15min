## 审查来源与补测

批量熔断与 CI 重试调整依据用户转述的 `43164eb` 复审意见。原浏览器验收中的街道任务使用受控 API 响应，未执行服务端真实批量循环，因此未覆盖此次误熔断。新增测试直接执行 `startStreetBatch`，仅替换上游检索和分析报告入口，报告由共享分析引擎离线生成。

修复前，两条“部分截断继续完成／截断成功重置失败计数”测试失败；修复后通过。另保留一条比建议条件更严格的边界检查：只有住宅返回完整结果、所有计分民生设施检索失败，不能作为真实零分社区参与排名。完整检索确认没有设施时，真实零分仍正常保留。

本轮仅调整社区是否计为分析失败，不改变共享评分、截断类别的未知语义或覆盖率计算。住宅截断时，批量结果仍保留 `coverageShare: null` 和 `coverageUnavailable: true`，不补造覆盖率。报告配额标记、配额异常、连续五个真实失败及取消操作仍阻止后续社区请求。

## 测试隔离与复现

浏览器测试服务为 `scripts/serve-browser-tests.mjs`，只托管构建产物，不加载 `.env`，外部域名请求被阻止。接口异常由测试提供受控响应；地图测试使用本地 SDK 替身。真实百度分析、地点检索和批量体检接口均未用于本轮回归，不消耗这些接口的 AK 配额。

```text
npm run typecheck
npm test
npm run build
npm run test:browser
```

Windows 受限执行环境曾阻止测试依赖读取及本地测试服务运行，产生 `EPERM`；在允许本地进程和端口的执行环境中重跑后通过，未将其计为产品故障。浏览器测试需要已安装 Playwright Chromium，默认使用本机 4183 端口。

浏览器截图及 PDF 在 `test-results/` 下，属于自动生成且被 Git 忽略的验收产物。它们使用合成验收社区，不能作为真实社区实测数据或正式参赛材料。
